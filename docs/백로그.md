## 기술 부채 / 알려진 이슈
- `MAX_ACTIVE_PER_HOUSEHOLD`, `MAX_VISIT_HOURS` 가 코드 상수 → 정책 테이블로 이동 (B-103)
- `redeliverStale` 와 PC 처리 사이 레이스: PC가 5분 넘게 처리 중이면 재전달될 수 있음 → PC 측 `jobId` 멱등 처리 필요
- 요금 집계는 현재 정책으로 재계산하지 않고 출차 시 확정값 사용, 진행 중 건만 현재 정책 → 정책 변경 시 혼재 (B-201)
- 앱 `registrationsProvider` 는 첫 페이지만 표시 (등록 목록 무한 스크롤 미구현)
- Gradle Wrapper 미포함 (네트워크 제약) → `gradle wrapper` 로 생성 필요
- Flutter 플랫폼 폴더(android/ios) 미포함 → `flutter create .` 로 생성
